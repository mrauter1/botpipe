# Readable history example

This directory is a real Botpipe state root generated by:

```bash
python docs/examples/readable-history/generate.py
```

Start with [`tasks/readable-task/runs/readable-run/ledger.jsonl`](tasks/readable-task/runs/readable-run/ledger.jsonl). Follow its relative references to `input.json`, `request.md`, and the attempt directories. The run includes an invalid provider response and repair, an accepted human answer, and an interrupted unsafe activity that the operator resolved as failed.
