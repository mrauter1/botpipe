# Prepare the security handoff

Package the reviewed remediation plan without overstating implementation or closure.

- `security_remediation_package` connects the finding, adopted evidence, threat assessment, selected remediation, rollout and rollback controls, verification obligations, and residual risk.
- `security_remediation_summary.json` contains `selected_remediation`, `verification_ready`, `rollout_ready`, and `authoritative_artifacts` consistent with upstream artifacts.
- `security_next_action` states the next authorized activity, owner role, prerequisites, stop conditions, approvals, and exact proof still required before closure.

Accept only when the package preserves reviewed facts and makes incomplete work unmistakable. Rework packaging drift; replan if the remediation or verification plan must change. Publication is not implementation, verification, risk acceptance, or closure.
