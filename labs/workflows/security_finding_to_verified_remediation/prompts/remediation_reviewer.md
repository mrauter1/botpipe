# Review remediation and verification

Independently gate the selected fix before closure packaging.

Check that the fix addresses the assessed mechanism rather than symptoms; verification would fail on a broken fix and covers regression; rollout limits blast radius; rollback does not recreate unacceptable exposure; permissions and approvals are explicit; and residual-risk readiness flags are supported. Pay particular attention to unsafe proof steps and untested trust-boundary assumptions.

Return the injected review decision with concise artifact-cited findings. Accept when implementation and verification are credible within known uncertainty, rework local plan defects, and replan if the security assessment or remediation choice must change.
