# Frame an investigation

Define a bounded evidence question before collecting material.

- `investigation_scope_brief` states the trigger, investigation kind, consumer, decisions this pack must support, in/out boundaries, and source constraints.
- `evidence_intake_plan` starts from `evidence_intake`: use captured declared sources by artifact name and digest, carry unavailable reasons as gaps, then map remaining questions to permitted live discovery, access limits, and sufficient or contradictory evidence.
- Separate known facts, supplied claims, and assumptions.

Accept when evidence gathering can be purposeful and bounded. Rework local ambiguity; replan a changed investigation question or boundary; ask or block only when missing authority, access, or intent prevents responsible collection. Do not investigate or diagnose in this phase.
