# Evidence Pack Checklist

- Scope brief defines the trigger, downstream consumer, in-scope boundary, out-of-scope boundary, and source constraints.
- Captured declared sources retain their artifact name and digest; unavailable declarations retain their reason.
- Evidence intake plan maps decision-relevant questions to permitted sources and sufficient proof.
- Source register records provenance, limits, and contribution for each inspected source.
- Source register distinguishes frozen declared evidence from additional live discovery.
- Findings distinguish observations, supported inferences, allegations, and unknowns.
- Contradictory evidence remains visible and its impact is explained.
- Gap register explains why each unresolved gap matters and what proof is still missing.
- Evidence pack summarizes scope, sources reviewed, key findings, unresolved gaps, and downstream handoff notes.
- `investigation_summary.json` is valid JSON and matches the durable evidence artifacts.
