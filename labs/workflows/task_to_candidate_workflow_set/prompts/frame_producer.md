# Frame candidate discovery

Define what a useful workflow candidate must accomplish. Use the request, parameters, and supplied catalog; an accepted result writes the declared artifacts before returning.

- `candidate_request_brief` captures the trigger, sponsor, desired terminal outcome, constraints, and downstream strategy decision.
- `workflow_fit_criteria` distinguishes direct fit, useful composition, safe adaptation, and a material portfolio gap. Include evidence expectations and disqualifying constraints.
- Record assumptions and facts whose absence limits comparison confidence.

Do not rank candidates here. Accept when the analyst can evaluate catalog entries consistently. Rework incomplete criteria locally, replan a changed objective, and ask or block only when a missing fact prevents meaningful discovery. Never invent catalog capabilities.
