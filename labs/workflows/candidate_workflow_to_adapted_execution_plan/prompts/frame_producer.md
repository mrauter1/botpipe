# Frame an adaptation

Fix the selected workflow as the subject and define the execution problem around it. Use the observed workflow contract rather than assumptions.

- `adaptation_request_brief` states the desired outcome, sponsor, constraints, why this workflow remains a plausible fit, and why adaptation is needed.
- `adaptation_success_criteria` separates invariant workflow behavior from task-specific choices and names the downstream evidence that will prove success.
- Surface missing task facts or contract ambiguity that could make adaptation unsafe.

Return the canonical selected workflow name in the typed result. Accept when analysis can proceed without changing the selected workflow. Rework local ambiguity; replan if selection or outcome must change; ask or block on a prerequisite that prevents a safe plan. Do not alter or run the workflow.
