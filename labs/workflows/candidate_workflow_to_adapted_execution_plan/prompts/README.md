# Prompt map

- `frame_producer.md` fixes the selected workflow and defines adaptation success.
- `analyze_producer.md` maps task needs to the observed contract and identifies unsafe or unsupported changes.
- `package_producer.md` publishes validated-parameter-ready execution guidance.

The runtime supplies the observed workflow contract, immutable prior artifacts, output paths, and typed schemas. The workflow plans adaptation only; it neither rewrites nor executes the selected workflow.
An `accepted` producer result requires every declared artifact. If a missing prerequisite makes responsible work impossible, `question` or `blocked` may pause without creating all outputs; never manufacture placeholder evidence merely to satisfy destinations.
