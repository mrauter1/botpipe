# Prompt map

- `frame_producer.md` defines release scope, policy, and evidence gates.
- `evidence_producer.md` assembles criterion-linked evidence; `evidence_reviewer.md` gates provenance and check classification.
- `assessment_producer.md` makes the decision; `assessment_reviewer.md` independently challenges blockers, conditions, and uncertainty.
- `package_producer.md` communicates the reviewed decision without changing it.

Reviewers remain on evidence and decision judgment. Final packaging has no separate reviewer and never executes or approves a release.

Declared release evidence is frozen once before framing; unavailable records remain decision inputs, and later live discovery must be labeled separately.
An `accepted` producer result requires every declared artifact. If a missing prerequisite makes responsible work impossible, `question` or `blocked` may pause without creating all outputs; never manufacture placeholder evidence merely to satisfy destinations.
