# Prompt map

- `frame_producer.md` defines portfolio scope and lifecycle criteria.
- `analyze_producer.md` makes one evidence-backed lifecycle recommendation per analyzed workflow.
- `package_producer.md` publishes governance and bounded next actions.

The runtime supplies catalog and run-health observations, immutable artifacts, destinations, and schemas. Sparse history and uncertainty remain visible; publication never mutates workflow packages.
An `accepted` producer result requires every declared artifact. If a missing prerequisite makes responsible work impossible, `question` or `blocked` may pause without creating all outputs; never manufacture placeholder evidence merely to satisfy destinations.
