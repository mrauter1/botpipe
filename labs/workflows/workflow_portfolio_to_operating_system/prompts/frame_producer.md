# Frame portfolio governance

Define the portfolio slice and the decisions this review must support using the catalog and observed run health.

- `portfolio_governance_brief` states sponsor intent, focus workflows, evidence window, operational goals, and exclusions.
- `lifecycle_criteria` defines evidence-sensitive tests for `keep`, `refine`, `decompose`, `merge`, and `retire`, plus when a genuine gap justifies `create_next`.
- Record sparse or biased run history rather than treating absence of evidence as poor health.

Accept when each in-scope workflow can be assessed consistently. Rework local ambiguity, replan a changed focus or governance goal, and ask or block only when a missing prerequisite prevents a responsible review. Do not make lifecycle recommendations yet.
